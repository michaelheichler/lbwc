# Source attribution and boundaries

## Source

This skill distills the principles taught in:

> **A Discipline of Programming**
> Edsger W. Dijkstra, 1976 (Prentice-Hall).

> **Structured Programming**
> Ole-Johan Dahl, Edsger W. Dijkstra, C. A. R. Hoare, 1972 (Academic Press).

All copyright in the books remains with the authors and publishers. This
repository is an independent, derivative *study aid* (a set of paraphrased,
agent-facing references) created for private use.

## What this repository contains (and does not)

- **References (`references/`)** are **paraphrased guidance written fresh**
  for this project. They do **not** reproduce either book's prose or its
  worked derivations in full. They restate the method (weakest
  preconditions, guarded commands, invariants, variant functions, stepwise
  refinement) in our own words, so an AI coding agent can apply it. Treat
  them as notes, not as the books.
- We do **not** redistribute either book, its text, its figures, or its
  original derivations.
