# Source attribution and boundaries

## Source

This skill distills the practices taught in:

> **Modern DevOps Practices, 2nd Edition**
> Gaurav Agarwal, 2024 (Packt Publishing).

All copyright in the book remains with the author and publisher. This repository
is an independent, derivative *study aid* (a set of paraphrased, agent-facing
references) created for private use.

## What this repository contains (and does not)

- **References (`references/`)** are **transformative distillations**
  (concepts, decision guidance, pitfalls) written fresh for this project.
  They do **not** reproduce the book's prose. Where the book ships an exact
  command, flag, or config template (for example a Terraform block or a
  `kubectl` invocation), our references preserve it verbatim so an agent
  reproduces the book's documented workflow. That carries over the book's
  operational instructions, not its explanatory text.
- We do **not** redistribute the book, its text, its figures, or its
  companion source code. The book's own companion repository is linked from
  `README.md` for readers who want the original.
- The packaged `modern-devops-practices.skill` artifact bundles only this
  repository's own `SKILL.md` and `references/`, not any book content.

If you are the author or publisher and would like any portion changed or removed,
