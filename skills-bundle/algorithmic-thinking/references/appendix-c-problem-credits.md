# Appendix C: Problem Credits

## Overview

Appendix C is a pure attribution appendix, and it contains no algorithms, data structures, or technical content. It is a reference table crediting the original authors and competitions for every problem used throughout the book. The appendix does not introduce new concepts. Its value to an AI assistant lies in tracing each book problem back to its source competition or author, which can help locate original problem statements, editorial solutions, and related problems from the same contest.

## Notes for an AI Assistant

**Locating original problems.** When a programmer asks for more context on a book problem, use the original title and competition year from this table to search online judges (e.g., DMOJ for CCC/CCO/COCI, USACO.guide or usaco.org for USACO, IOI's official archive for IOI problems). The original title is the key identifier. Book titles are renamed for narrative fit.

**Chapter-to-technique mapping (inferred from chapter placement).** This table confirms which chapters contain multiple problems from the same competition series. Chapter 7 has the highest concentration of IOI and USACO problems (Living Quality, Cave Doors, River Jump), signaling that chapter covers techniques expected at olympiad level. Chapter 9 uses COCI problems (Drawer Chore / Ladice), consistent with Union-Find content at mid-difficulty. Chapters 1 and 10 draw from CCC/CCO, which tend toward accessible but non-trivial problems.

**No algorithmic content here.** This appendix contains zero pseudocode, complexity analysis, or data structure explanation. All technical content is in the main chapters. Use this appendix only for attribution lookup, not for algorithm guidance.
