# Source attribution and boundaries

## Source

This skill distills the principles taught in:

> **Algorithmic Thinking: Unlock Your Programming Potential, 2nd Edition**
> Daniel Zingaro, 2024 (No Starch Press).

All copyright in the book remains with the author and publisher. This repository
is an independent, derivative *study aid* (a set of paraphrased, agent-facing
references plus original problem-pattern guidance) created for private use.

## What this repository contains (and does not)

- **References (`references/`)** are **paraphrased guidance written fresh**
  for this project. They do **not** reproduce the book's prose. They restate
  the book's algorithmic patterns and problem-solving framework in our own
  words, so an AI coding agent can apply them. Treat them as notes, not as
  the book.
- **`references/appendix-c-problem-credits.md`** is a factual attribution
  table crediting the original competitions and authors of the problems the
  book discusses (CCC, CCO, USACO, IOI, and others). It restates that
  attribution, not the book's text.
- We do **not** redistribute the book, its text, its figures, or its
  original problem statements or editorial solutions.
