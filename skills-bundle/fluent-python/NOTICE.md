# Source attribution and boundaries

## Source

This skill distills the principles taught in:

> **Fluent Python, 2nd Edition**
> Luciano Ramalho, 2022 (O'Reilly Media).

All copyright in the book remains with the author and publisher. This
repository is an independent, derivative *study aid* (a set of paraphrased,
agent-facing chapter references) created for private use.

## What this repository contains (and does not)

- **References (`claude-code/fluent-python/references/` and
  `codex/fluent-python/references/`)** are **paraphrased guidance written
  fresh** for this project. They do **not** reproduce the book's prose. They
  restate the book's Python design guidance (data model, collections,
  dataclasses, protocols, iterators, concurrency, async, descriptors, and
  metaprogramming) in our own words, so an AI coding agent can apply them.
  Treat them as notes, not as the book.
- We do **not** redistribute the book, its text, its figures, or its
  original code listings.
